Evidence and limits

Deterministic API fixtures intercept every /api/ request by pathname; unknown routes fail closed. No live content was written. Synthetic auth material is generated per run, held in memory and excluded from screenshots and logs. No real phone, code, token, launch data or device location was used.

The controlled native adapter demonstrates browser integration with simulated Telegram callbacks. It does not demonstrate physical permission dialogs, contact sharing, Telegram client chrome, real keyboard occlusion, device safe areas, real GPS accuracy, iOS/Android touch behavior or camera/image-library selection. Those remain Task 9 checks. Provider availability and configured browser-facing map credentials remain external requirements. The production bundle still has a greater-than-500kB notice and old Browserslist data; no dependency upgrade was made.

On visible Create sheets at or below 400px, Create stays in the single scroller so fields remain usable; reaching submit can require scrolling. Close remains available in its separate footer. At ordinary sheet heights Create remains sticky, with focus padding based on its measured height.
