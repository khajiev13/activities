> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the approved phone-first Eventopia experience: map-led city discovery, persistent bottom navigation, usable forms, and optional device-location city selection.

**Architecture:** Reuse React Router, the authenticated API client, Radix/Vaul primitives and MapTiler layers. Keep native Telegram UI capabilities and read-only device-location resolution separate from authentication and location creation.

## Global Constraints

- “Four labeled destinations: Explore, Activities, Teams, Organizations. Create remains a contextual action. Desktop gets a rail and a results panel.”
- “Use 44–48px app controls, readable labels, visible focus and measured contrast.” Use 16px inputs and readable 12px-or-larger secondary copy; main card titles/body 16px.
- “Changing views preserves the city, entity and text search. Returning from a detail or login restores that context and the list position.”
- “Moving the map changes the view only; results remain city-scoped.” Preserve explicit country/state browsing as an alternative.
- “A first visit offers ‘Use my location’ and manual city search. It does not assume Beijing is the visitor’s city.”
- “Auto-select only a unique match with compatible country and state, then query using the exact stored names.” Manual selection wins over pending GPS callbacks.
